La mia Bookshelf è una web app realizzata con HTML, CSS e JavaScript durante il Week Project — Settimana III di Epicode.

L'obiettivo del progetto è creare una libreria personale in cui poter aggiungere libri, organizzare quelli letti e quelli ancora da leggere e tenere traccia dei propri progressi.

Funzionalità

Aggiungere un libro inserendo titolo, autore, anno e stato di lettura.

Modificare le informazioni di un libro.

Eliminare un libro dalla lista.

Cambiare lo stato di un libro da letto a da leggere e viceversa.

Cercare i libri per titolo o autore.

Filtrare i libri in base allo stato di lettura.

Ordinare i libri per anno o per titolo.

Visualizzare il numero totale dei libri, quelli letti e quelli da leggere.

Visualizzare una barra di progresso con la percentuale dei libri letti.

Passare dal tema chiaro al tema scuro.

Ricevere notifiche dopo le principali operazioni.

Salvare i libri nel browser tramite LocalStorage, in modo da ritrovarli anche dopo aver ricaricato la pagina.

Tecnologie utilizzate

HTML per la struttura della pagina.

CSS per la grafica, i colori, il tema scuro e l'adattamento agli schermi più piccoli.

JavaScript per gestire i libri, le funzionalità e le interazioni con la pagina.

LocalStorage per salvare i dati nel browser.

Struttura dei file

index.html: contiene la struttura della pagina.

style.css: contiene gli stili e la grafica.

script.js: contiene la logica JavaScript e tutte le funzionalità della web app.

Come funziona

I libri vengono gestiti tramite un array di oggetti JavaScript. Quando si aggiunge, modifica o elimina un libro, la lista viene aggiornata automaticamente.

La ricerca, i filtri e l'ordinamento permettono di organizzare i libri in base alle proprie esigenze. Le statistiche e la barra di progresso si aggiornano in base ai libri presenti e al loro stato di lettura.

I dati vengono salvati nel LocalStorage del browser, così da rimanere disponibili anche dopo aver chiuso o ricaricato la pagina.
